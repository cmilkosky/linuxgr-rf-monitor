## Home Linux Ops Access

For automated maintenance, health checks, service management, Docker work, package installs, app deployments, and system fixes on my home Linux hosts, use the ops SSH aliases and the `codexops` account:

- `linux2-ops`
- `linux4-ops`
- `linuxGR-ops`
- `jetson-ops`

These aliases use key-based SSH and passwordless sudo. Do not use root SSH by default. My ordinary host aliases like `linux2`, `linux4`, `linuxGR`, and `jetson` are for my personal `cmilkosk` interactive logins.
